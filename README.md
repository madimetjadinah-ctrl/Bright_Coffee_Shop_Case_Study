# Bright_Coffee_Shop_Case_Study sales Analysis

📌 Project Overview
The project analyzes transactional sales data from Bright Coffee Shop to provide actionable business insights for executive decision-making. The goal is to identify revenue drivers, understand sales patterns, and recommend strategies to improve overall business performance.
The project demonstrates the complete analytics lifecycle, including:
Data architecture planning
Data processing and transformation
Sales analysis and visualization
Executive reporting and recommendations

🎯 Business Objectives
The analysis aims to answer the following key questions:
Which products generate the highest revenue?
At what times does the coffee shop perform best?
What sales trends exist across products and time intervals?
What recommendations can increase revenue and improve performance?
